Push notifications for Beacon servers

The Beacon app only receives push notifications sent through this relay, run by the MeshCore Beacon project. If you run your own beacon-server, register it here to send its alerts to your users' phones.

What the relay sees

  • Which server sent each notification. Every notification shows your server's name.
  • When it was sent, which device handle it went to, and its size.
  • Not what it says. Notifications are encrypted between your server and the app.

Each server has rate limits, and the relay tracks usage to catch abuse. Servers that abuse it are suspended or banned.
