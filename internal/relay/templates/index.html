Push for Beacon servers

The Beacon app only accepts notifications sent through this relay. Run your own beacon-server? Register it so its alerts reach your users.

What the relay sees

  • Which server sent each notification, and when.
  • The device it went to, and the size.

It can't read them: they're encrypted between your server and the app.

Register a server

Already registered? Manage your servers to get a new secret or remove one.

Keeping it running

I host this relay in the cloud so every Beacon user gets notifications, free for you and your users. If it's useful to you, you can help cover the hosting.
